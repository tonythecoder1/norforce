NORFORCE — website estático

1. Abra index.html num navegador para visualizar.
2. Para publicar, carregue index.html para um serviço de alojamento estático (Netlify, Cloudflare Pages, GitHub Pages, etc.).
3. O logótipo no cabeçalho é recriado em tipografia CSS; logo-reference.png é o conceito visual original.
4. As fotografias são carregadas a partir de URLs do Unsplash e requerem Internet. Substitua-as por fotografias próprias/licenciadas antes da publicação definitiva.
5. Os formulários abrem o cliente de email do visitante (mailto:). Não guardam candidaturas nem enviam emails automaticamente.
6. Confirme o email de contacto, política de privacidade, aviso de cookies se aplicável e requisitos IEFP/APC antes de publicar e iniciar a atividade.
